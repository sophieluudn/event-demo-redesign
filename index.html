活動簡介

生成式AI浪潮席捲全球產業，人工智慧已從單一工具應用，逐步邁向具備自主判斷、協作與執行能力的 AI Agent 時代。隨著大型語言模型、企業數據平台及智慧應用快速成熟，AI Agent 正重新定義企業營運模式、商業流程與市場競爭規則，開啟新一波產業轉型契機。

在全球數位競逐加速之際，企業如何善用 AI Agent 建立營運韌性、提升決策效率、打造智慧服務與創新商模，已成為產官學界共同關注的重要課題。

經濟日報再度以「AI Agent新賽局」為主題舉辦【2026科技論壇】，匯聚政府代表、科技領袖、產業專家與企業決策者，共同探討 AI Agent 發展趨勢、關鍵技術、應用場景與產業布局，協助企業掌握智慧轉型關鍵契機，布局下一世代競爭優勢。
