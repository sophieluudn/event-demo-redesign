# 開發驗收清單

每完成一頁執行相關項目；正式交付前再做全站回歸。

## 範圍與既有功能

- [ ] Vue 涵蓋 Demo 的 7 個頁面情境。
- [ ] 既有登入、報名、審核、付款、OTP、查詢及憑證流程未被破壞。
- [ ] Demo 假資料、假 QR Code 與靜態跳頁未進入正式邏輯。
- [ ] Demo 與既有系統的差異已列出並確認。

## 視覺與 Ant Design Vue

- [ ] 字體為 Noto Sans TC 及指定 fallback。
- [ ] 正文 20px，Ant Design Vue 主要元件文字 18px。
- [ ] H1、H2、H3 在手機與桌機符合規格。
- [ ] Button、Input、Select 基本高度 40px。
- [ ] 色彩、邊框、圓角及間距與 Demo 一致。
- [ ] Ant Design Vue 預設小字、padding、Modal 尺寸未破壞版面。
- [ ] 共用差異使用 theme／共用樣式，無散落大量 `!important`。
- [ ] 已在 375、768、1024、1440px 比對 Demo。
- [ ] 無非預期水平捲動。
- [ ] 長姓名、Email、公司名稱及活動名稱不破版。

## 導覽與連結

- [ ] 桌機及手機導覽正確。
- [ ] 手機選單狀態與 `aria-expanded` 同步。
- [ ] 首頁錨點不被 sticky header 遮住。
- [ ] 返回、報名、查詢及付款入口目的地正確。
- [ ] 外部連結另開時具安全屬性。
- [ ] 全站沒有 `mailto:`。
- [ ] 全站沒有 `tel:`。

## 表單

- [ ] 欄位都有可見 label 及正確關聯。
- [ ] 必填與格式驗證正確。
- [ ] 錯誤不會在使用者操作前不必要地顯示。
- [ ] 錯誤可被輔助科技感知。
- [ ] 送出錯誤後輸入內容不會無故遺失。
- [ ] 送出期間有 loading、disabled 及防重複送出。
- [ ] 後端錯誤可對應至欄位或錯誤摘要。
- [ ] 未同意個資時不可送出。

## OTP 與查詢

- [ ] 手機格式錯誤時不發送 OTP。
- [ ] 發送中、已發送、倒數、重送、失敗、過期、限制皆可處理。
- [ ] OTP 支援數字鍵盤與 one-time-code autocomplete。
- [ ] 驗證成功前不可查看報名資料。
- [ ] 查無結果有空狀態及重新查詢。
- [ ] 結果筆數與卡片數一致。
- [ ] 個資依既有規則遮罩。

## 狀態與付款

- [ ] 完成報名可查看 QR Code。
- [ ] 審核中不顯示不適用操作。
- [ ] 等待付款顯示付款入口。
- [ ] 審核未過不顯示付款或憑證。
- [ ] 使用狀態碼 mapping，不以中文文案判斷。
- [ ] 付款按鈕防止重複提交。
- [ ] 付款成功由後端可信結果判定。
- [ ] 取消、失敗、待確認及重複回跳已測試。

## Modal、QR Code 與列印

- [ ] Modal 開啟後焦點正確，背景不可操作。
- [ ] 關閉按鈕及 Esc 可關閉，焦點回到觸發元件。
- [ ] 小螢幕及 200% 放大仍可捲動、關閉。
- [ ] QR Code 使用正式資料且實機可掃描。
- [ ] 列印只含憑證必要內容。
- [ ] QR Code 與序號未被裁切。

## 無障礙

- [ ] 全站可只用鍵盤操作。
- [ ] 焦點順序合理且樣式清楚。
- [ ] 狀態與錯誤不只靠顏色。
- [ ] 圖片、圖示按鈕、iframe 有合適名稱。
- [ ] 每頁有一個主要 H1，標題層級合理。
- [ ] 文字放大至 200% 仍可閱讀操作。
- [ ] 文字及控制項符合 WCAG AA 對比。
- [ ] 動態訊息能由輔助科技接收。

## 相容性與品質

- [ ] 最新穩定版 Chrome、Edge、Safari 已測試。
- [ ] iOS Safari、Android Chrome 已測試。
- [ ] 無 JavaScript runtime error 或 Vue warning。
- [ ] 無失敗資源請求或混合內容警告。
- [ ] 不支援的新 CSS 功能已有 fallback。
- [ ] 圖片、字型及首屏效能可接受。

## 隱私與安全

- [ ] 個資、OTP、付款資料不寫入 console。
- [ ] 個資不放入不必要的 URL query string。
- [ ] 分析及錯誤追蹤不蒐集敏感欄位。
- [ ] OTP、付款、資格及憑證均由後端驗證。
- [ ] 外部 iframe、連結符合既有 CSP、隱私及資安規範。
